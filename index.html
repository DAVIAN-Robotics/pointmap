Motivation

Manipulation Needs the Target's Position Relative to the Gripper

Manipulation requires the target position relative to the end effector. RGB leaves this 3D relationship implicit. Depth measures distance from the camera.

Back-projecting depth with camera intrinsics gives each pixel a 3D position. Keeping these positions on the same dense image grid as RGB produces a pointmap. Expressing them in robot coordinates makes a visible scene point's coordinates independent of camera placement. Centering them at the gripper directly exposes the geometry of the interaction.

Solution

Robot-Centric Geometry on the RGB Grid

SeeR-VLA augments a pretrained VLA with an image-aligned H × W × 3 pointmap for each view. We lift depth into 3D and transform the points into the robot base frame. We then subtract the current end-effector position. This changes the origin while preserving the robot-base axis directions.

  • Dense geometry. Keep a 3D coordinate at each valid RGB pixel.
  • A common robot reference. Express all views in the same robot coordinate frame.
  • Aligned feature fusion. Add matching RGB and pointmap features without adding tokens.

Ablation Studies

Which Representation and Fusion Work Best?

Controlled comparisons examine how to represent 3D geometry and how to combine it with RGB. These studies use pretrained VLM weights without robot-action pretraining. The coordinate frame is fixed to the robot base.

1Provide Explicit 3D Coordinates▼

Depth and Plücker rays together provide the information needed to recover robot-frame geometry. Constructing pointmaps explicitly improves success from 31.7% to 34.4%.

2Add Features at Corresponding Image Locations▼

Separate encoders preserve each modality's representation. Adding their spatially aligned features performs best and keeps the number of visual tokens unchanged.

Analysis

1Viewpoint Diversity▼

The advantage over RGB-only policies grows as training camera placements become more varied. The pointmaps express geometry in a common robot reference even as its appearance changes across viewpoints.

(a) Where Do Inputs Affect the Action?

Brighter regions indicate where small input changes have a larger effect on predicted motion.
